# 📁 VocabMaster – Prompt & Changelog Log

Folder này ghi lại toàn bộ lịch sử prompt người dùng và các thay đổi tương ứng.
Dùng để tái tạo hoặc mở rộng dự án trong tương lai.

---

## 📂 Cấu trúc

```
.agents/
├── README.md          ← File này
├── prompts/
│   └── 001_initial.md ← Prompt khởi tạo dự án
└── changelog/
    └── CHANGELOG.md   ← Lịch sử thay đổi theo phiên bản
```

## 💡 Cách dùng

Mỗi lần thêm tính năng mới:
1. Mô tả yêu cầu vào file `prompts/00X_feature_name.md`
2. Ghi nhận thay đổi vào `changelog/CHANGELOG.md`
